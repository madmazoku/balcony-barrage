# Changelog
## [0.7.0] - 2026-11-06 (AI-7)
### Added
- Первая принятая группа фазы 5: отдача выстрела, четыре кадра лопания каждого цвета и отлёт брони.
- Отдельные данные эффектов, события уже применённого урона и проверки жизненного цикла анимации.
### Fixed
- Убегающий миньон показывает конкретную украденную деталь.

## [0.6.0] - 2026-11-06 (AI-6)
### Fixed
- Наклонные верёвки крепятся к нижним хвостикам шариков, сохраняя центры и зоны попадания.
- Боковые позы арбалета совмещены с кистью Гаечки вместо уровня головы; привязка сохранена в манифесте подготовки.

## [0.5.0] - 2026-11-06 (AI-5)
### Added
- Браузерный профиль Godot и публичная игровая страница GitHub Pages.
- Автоматические проверки PR и обновление страницы только после успешного объединения принятой версии в master.
- Проверка SHA512 официального редактора/шаблонов, кеширование инструментов и данные версии опубликованной сборки.
### Changed
- Репозиторий публичный по прямому запросу владельца; порядок приёмки и публикации записан для дальнейшей работы.
- Подсказка клавиатуры использует слово «стрелки», чтобы не терять символы в браузерном шрифте.

## [0.4.0] - 2026-11-06 (AI-4)
### Added
- Фаза 4 — статичный пакет Rescue Rangers из 47 PNG на единой модели FLUX.2 Klein 9B.
- Независимые слои оружия и брони, позы Гаечки, персонажи, палитры миньонов, шарики, предметы и окружение.
- Повреждения балкона, происхождение ресурсов, исходники и воспроизводимая подготовка.
- Проверка контракта пакетов и инструмент визуальных QA-кадров.
### Fixed
- После обрушения босс видимо падает с ускорением; побитый спрайт и экран победы появляются после приземления.
- Разрушения сохраняют исходный ходовой настил, накапливаются на обшивке и подпорках.
- На победе используется отдельный спрайт побитого сидящего босса.
### Changed
- Графический пакет выбран по умолчанию, исходные прототипы остаются переключаемыми.
- Атака босса мебелью включена по умолчанию по решению владельца; переключатель сохранён.
- Линейная фильтрация с mipmaps обеспечивает корректное уменьшение спрайтов.

## [0.3.0] - 2026-11-05 (AI-3)
### Added
- Фаза 3 — аналоговый стик, крестовина, кнопки выстрела, повтора и паузы.
- Сенсорное перетаскивание, направленные тапы, второй палец и проверка мышью.
- Отдельный конфиг управления и тесты обработки событий в сцене.
### Changed
- Потеря фокуса и отключение активного контроллера ставят игру на паузу, жесты отменяются.

## [0.2.0] - 2026-11-05 (AI-2)
### Fixed
- Метатели ограничивают бросок гайки конусом вниз, предел задаётся nut_max_angle_degrees в gameplay.tres (35°).

### Added
- Фаза 2 — полный клавиатурный раунд на фигурах, три типа миньонов, наземная погоня и броня.
- Болты с конечной скоростью и первым попаданием, прыжки босса и последовательный обвал.
- Проверочные ситуации, пауза, рестарт, эксперимент с мебелью и второй пакет палитр.
- Проверки механики, реального ввода и перезапуска сцены.

## [0.1.0] - 2026-11-05 (AI-1)

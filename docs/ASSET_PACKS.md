# Пакеты оформления
config/presentation.tres — единственная точка выбора. Пакет загружается при запуске сцены, его валидация происходит до начала раунда. Каждый пакет явно описывает свои ресурсы, скрытых fallback нет.

## Категории и контракт static
| Поле | Содержимое |
|---|---|
| characters | player, boss, boss_defeated, normal, tank, thrower; player_right/left/up; armor_0_right и аналогичные 9 слоёв |
| character_variants | массивы Texture2D для normal, tank, thrower; текущие базовая, тёплая и тёмная палитры |
| environment | background, ground, balcony_0 ... balcony_5 |
| effects | crossbow и crossbow_right/left/up, bolt, nut, sack, furniture, rope, armor_0/1/2 |
| balloon_sprites | отдельные Texture2D для каждого цвета; порядок соответствует balloon_palette |
| ui | дополнительные UI-ресурсы при их наличии; сейчас используются стандартные Control и цвета пакета |
| sfx, music | аудио; audio_mode=silent явно объявляет отсутствие в статичной версии |
| display_names, colors | подписи ролей и палитра; у static также hud_panel, result_panel, touch_boundary |

Текущая реализация поддерживает readiness=prototype и static. Animated потребует расширения контракта в фазе 5.
Все foreground PNG имеют прозрачность. Полностью прозрачный balcony_5 обозначает окончательное обрушение.

## Привязки
Кадры Гаечки, её оружия и брони имеют общий холст 768x896. player_anchor=(384,872) — точка опоры ног. player_body_height=495 определяет масштаб относительно высоты игрового хитбокса.
При подготовке разные позы нормализованы по опоре и масштабу головы. Арбалет и каждая деталь брони включаются независимо. Предметы effects/armor_0...2 также доступны в обрезанном виде для будущего отлёта.
balcony_draw_height задаёт только высоту картинки балкона. Пять визуальных ступеней отображаются пропорционально числу ступеней здоровья босса из gameplay.
Игровая геометрия, HP, скорости, тайминги, вероятность и урон находятся в gameplay.tres. Изменения спрайтов не должны менять эти правила.

## Подготовка и происхождение
Весь статичный набор rescue_rangers получен через FLUX.2 Klein 9B FP8 с общими параметрами из art-lock.json. Цветовые варианты, зеркалирование, удаление фона, crop, масштабирование и alpha-композиция выполняются детерминированно из сгенерированных пикселей. Рисованные накладки оружия запрещены.
Исходники и производные слои для повторной подготовки — art/sources/rescue_rangers. Небольшие speckle-компоненты отделённой гайки у носа метателя убраны при вырезке по связанному компоненту.
art/build-static-pack.json содержит входы для существующей утилиты Gemini/scripts/sprite_assets.py build-pack. Файл asset-preparation.json описывает преобразования, provenance хранит исходные спецификации, checksums.json — итоговые PNG.
Хранить .png.import с mipmaps/generate=true, основной CanvasItem использует линейную фильтрацию с mipmaps.

## Проверки
tools/test_asset_pack.gd проверяет все нужные слоты, прозрачность, неверные пакеты и воспроизводимость боя при смене static ↔ prototype через реальную сцену.
tools/capture_pack.gd сохраняет воспроизводимый кадр для проверки направлений и состояний брони.
Технические картинки из art/drafts и исторические кандидаты не являются fallback для runtime.

## Балкон и финальный босс
Все стадии балкона имеют единый кадр 985x250, balcony_draw_height=125; исходные видимые 200 пикселей продолжают отображаться высотой 100. Верхние 87 строк исходного настила не изменяются до финального обрушения. Подпорки заменяются сгенерированными обломками, обшивка берётся из последовательных масочных изменений только ниже настила. Все crop, позиции и порядок перечислены в balcony_preparation манифеста; это данные подготовки оформления, не параметры боя.
Во время финального падения перемещается characters/boss, после касания земли используется отдельный обязательный characters/boss_defeated и открывается экран победы. Покадровая поза падения относится к фазе 5; само перемещение с ускорением уже реализовано в фазе 4 по замечанию владельца.
